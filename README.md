# TaskFolders 1.0.0

TaskFolders размещает папки приложений внутри основной панели задач Windows 11 рядом с областью уведомлений. Наведение открывает полупрозрачное окно со скруглёнными углами через 200 мс. На значке папки отображаются миниатюры первых трёх приложений. Щелчок по папке закрепляет окно. Повторный щелчок или Escape закрывает его.

**Страницы.** По умолчанию на странице четыре приложения (2×2). С пятого приложения внизу появляются номер страницы и стрелки. Правая стрелка открывает следующую страницу, левая возвращает назад. Можно использовать колесо мыши. В редакторе для отдельной папки доступна сетка 4×4 до 16 приложений на страницу.

**Фон.** Щёлкните правой кнопкой по папке или внутри открытой сетки. Выберите файл PNG, JPEG или BMP, иконку первого добавленного приложения или стекло без картинки. Выбор сохраняется для этой папки. Файл картинки должен оставаться по выбранному пути.

**Общие настройки.** Щёлкните правой кнопкой по чёрной папке и выберите **Настройки…**. Название по умолчанию скрыто. Включите «Подпись под папкой» для нужной папки, чтобы вернуть его. Раздел **Папки** управляет ярлыками, сеткой и фоном. Изменения папок записываются кнопкой «Сохранить». Раздел **Устройства и заряд** показывает дерево команд работающего BatteryHub. Раскройте устройство для видимости, порядка, имени, истории и предупреждений. Общие параметры включают интервал опроса, расположение, оформление, язык и автозапуск монитора. Доступные команды зависят от устройств и возможностей сборки. Выберите параметр и нажмите «Применить выбранное». Команда устройства выполняется сразу. Щелчок по виджету заряда открывает этот же раздел.

**Индикатор мыши.** При 5–19% значок жёлтый, при 0–4% красный. От 20% используется обычный цвет. Штатный период проверки — 5 минут. Кнопка «Обновить заряд» запускает внеочередную проверку.

**Радиоканал.** Для Logitech LIGHTSPEED с USB ID 046D:C54D монитор опрашивает сопряжённые слоты по HID++, повторяет запрос коротким отчётом и читает имя сопряжённой мыши из памяти приёмника при ответе «устройство недоступно». Уведомление о восстановлении радиосвязи инициирует внеочередное чтение. Пока мышь спит или отключена, в настройках доступен её статус. Включите «Показывать отключённые устройства», если хотите видеть этот статус на панели задач. Для разового опроса выберите «Обновить сейчас».

## Данные

Настройки сохраняются в `%LOCALAPPDATA%\TaskFolders\folders.dat`. Для переносимого запуска используйте `TaskFolders.exe --portable` из папки с правом записи. Тогда данные хранятся рядом с EXE. Для резервного копирования достаточно скопировать folders.dat. Ссылки внутри файла содержат абсолютные пути.

Хранилище проверяет версию, длины и размеры записей. При сохранении сначала записывается временный файл, затем Windows заменяет основной. При повреждении конфигурации запуск останавливается с сообщением. Для восстановления сохраните копию повреждённого файла и верните резервную либо переименуйте его для запуска с пустой папкой.

## Сборка и проверка

Для первоначальной загрузки официального архива BatteryHub требуется доступ к GitHub. CMake проверяет SHA-256 официальной поставки вспомогательных файлов. Монитор компилируется из исходников BatteryHub 1.1.0 с патчем TaskFolders. Требуются CMake 3.15+, Git, MSVC для TaskFolders, Windows SDK и MinGW-w64 с g++ и windres для монитора. Если MinGW отсутствует в PATH, передайте CMake параметр -DTASKFOLDERS_MINGW_BIN с путём к его каталогу bin. В командной строке разработчика Visual Studio выполните:

```powershell
cmake -S . -B build -A x64
cmake --build build --config Release
ctest --test-dir build -C Release --output-on-failure
cpack --config build/CPackConfig.cmake -C Release -B dist
```

EXE находится в `build/Release`. Для проверки интерфейса закройте TaskFolders и выполните на интерактивном рабочем столе:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File tests/desktop.ps1 -Exe build/Release/TaskFolders.exe
```

Тест использует временную переносимую копию, перемещает курсор на папку, запускает проверочный ярлык, создаёт папку через редактор и проверяет файл конфигурации. По окончании закрывает копию и возвращает курсор. GitHub Actions собирает Release x64, выполняет тест хранилища и готовит ZIP-артефакт.

## Интеграция

Полоса папок — дочернее окно Shell_TrayWnd со стилем WS_CHILD. TaskFolders рассчитывает доступную ширину по координатам TrayNotifyWnd и области кнопок MSTaskSwWClass. Полоса перемещается вместе с панелью задач при автоскрытии. Сетка открывается в отдельном окне процесса TaskFolders. Использован подход Wireless Device Battery Monitor. [Исходный проект](https://github.com/krisgfx9/Wireless-Device-Battery-Monitor/blob/main/src/widget.cpp)

Изменения положения отслеживаются через внешние уведомления WinEvent. Скрытое окно TaskFolders получает TaskbarCreated и повторно подключает полосу. Если места на папку недостаточно или геометрию кнопок определить невозможно, управление доступно через значок TaskFolders в области уведомлений. Левая кнопка открывает редактор, правая — меню с выходом. При появлении места папки возвращаются внутрь панели.

## Проверка версии 1.0.0

Локальная Release-сборка и тесты выполнены на Windows 11 Pro x64, сборка 26200, MSVC 19.29, SDK 10.0.19041.0. Тест хранилища проверяет чтение и запись Unicode, пустой набор папок, повреждённый файл и сохранность предыдущей версии после ошибки записи. На интерактивном рабочем столе проверены открытие по наведению, переход курсора в сетку, запуск программы через LNK и сохранение новой папки из редактора.

В сценарии с пятью ярлыками тест перелистывает страницу стрелкой и запускает пятый ярлык. Тест проверяет родительское окно полосы, размещение внутри панели задач до начала области уведомлений и открытие сетки после раскрытия панели. На тестовой машине включено автоскрытие. Отдельная проверка с запущенным BatteryHub подтвердила порядок окон папок, индикатора устройств и системного трея. Сканирование обнаружило Logitech PRO X 2.

## Ограничения

- Поддерживается основная горизонтальная панель задач. Геометрия внутренних окон Explorer зависит от версии Windows. Реальный перезапуск Explorer, дополнительные экраны и конфигурации с другим масштабом требуют отдельных проверок.
- Сетка адаптируется к доступной ширине и высоте рабочего стола. Используются системные иконки и фиксированные задержки. Цвет панелей следует настройке темы Windows. Редактор использует стандартные элементы системного диалога.
- Запуск EXE, LNK и URL передаётся Windows Shell. Ярлыки Steam используют установленный обработчик URI. Каталог установленных программ и прямая активация по AppUserModelID в эту версию не входят.
- Горячие клавиши, поиск, избранное, профили, автозапуск, настройка оформления, сортировка перетаскиванием, экспорт JSON и установщик отложены до последующих версий. Поставка первой версии включает EXE и ZIP.

Исходный код TaskFolders распространяется по MIT. У BatteryHub и HeadsetControl собственные лицензии. В поставку включены уведомления и ссылки на соответствующие исходники в папке BatteryHub.


Вкладка «Музыкальные клавиши» содержит паузу, переключение треков и громкость,
как в Control Desk. Нажмите поле справа от действия, задайте сочетание и включите
«Включить музыкальные сочетания». Кнопка «Готово» проверяет занятость и сохраняет
назначения. «Сброс» удаляет назначение. Кнопки самих действий работают сразу.
Если получателей несколько, плеер выбирает Windows.

Галочка «Запускать TaskFolders при входе в Windows» управляет автозапуском всей
программы. Вкладка «Папки» позволяет удалить все папки, затем сохранить пустой
список. Настройки остаются доступны через системный трей и индикатор мыши.
Иконка мыши в спящем режиме остаётся чёрной с полной непрозрачностью.
Цветные предупреждения о низком заряде применяются к свежему показанию.
